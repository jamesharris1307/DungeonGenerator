
# Dungeon Generator

---

## What I built

---

I am building a Dungeon Generator in C# .Net10

## Why I built it

---

I build it because I have little experience in C# 
and Procedural Generation. I was working on a Game 
project in my game engine of choice Godot, 
using gdScript and I thought procedural generation 
would make my game more fun. I ended up moving onto
a different project and subsequently not implementing
the procedural generation. 

Since this technical assessment encouraged using 
a new technology I haven't used before and also to
create something I found interesting I decided to do
this.


## How to Run

---

Docker 

## How it Works

---

The user inputs a size for the map, the code creates
walls over each cell in the 2D array. A starter 
room is placed randomly within the 2D array and
creates more rooms everywhere else

## What I would improve:

---

I would make the project compatible with game engines
such as Unity and Godot to allow more developers 
to use the program. I would create gui to better
represent the dungeon creator process so the user
can watch their dungeon get created in real time.
