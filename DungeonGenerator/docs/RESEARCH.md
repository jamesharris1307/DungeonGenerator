## 3. Problems Encountered

### Problem 1: Removing Rider Configuration Files from Git

My first problem occurred when making my initial Git commit. I accidentally included the `.idea/` directory, which is generated by JetBrains Rider and contains IDE configuration files.

I was concerned that removing this directory from GitHub would also delete it from my local project, potentially causing problems with my Rider configuration.

After researching Git, I discovered the `--cached` option for the `git rm` command.

I used the following commands:

```bash
git rm -r --cached .idea
git add .gitignore
git commit -m "Remove Rider configuration from repository"
git push
```

This removed the `.idea/` directory from Git tracking without deleting the local files.

I also added `.idea/` to my `.gitignore` file to prevent it from being tracked in future commits.
